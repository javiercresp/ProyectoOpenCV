
# Basketball Shot Tracker

Proyecto de Visión por Computador desarrollado con Python y OpenCV.

## Descripción

Sistema de análisis de lanzamientos de baloncesto mediante técnicas clásicas de procesamiento digital de imágenes, sin utilizar Inteligencia Artificial ni Machine Learning.

## Funcionalidades

- Detección del balón mediante segmentación de color HSV.
- Seguimiento de la trayectoria del balón.

## Tecnologías

- Python
- OpenCV
- NumPy

## Estado del proyecto

Primera versión: seguimiento de la pelota.

El proyecto se ampliará progresivamente para incorporar la selección manual del aro y la detección de canastas.
